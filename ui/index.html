平台账号与下载组件

B站可扫码登录。X 与 YouTube 默认公开访问，需要账号权限时导入 Cookie，再在解析页选择“使用登录状态”。

Bilibili（B站）未登录

登录后可使用账号权限内的画质，以及收藏夹、稍后再看和观看历史。左侧头像也可查看账号。

X 未导入 Cookie

导入 X 的 Netscape 格式 cookies.txt。默认仅本次使用；需要账号权限时再选择使用登录状态。

YouTube 未导入 Cookie

可导入已登录浏览器的 cookies.txt。默认仅本次使用；勾选记住后才会保存，取消勾选或清除 Cookie 可删除副本。

首次解析会从 yt-dlp 官方 GitHub 下载组件并校验文件。后续使用本地副本。
